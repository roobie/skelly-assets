The manifest lists the dolls a figure can be built as, `dolls`: each one's `id`, `pack`, `rig` file under that pack and the `models` of its bust and limbs. The player is the only doll, and its rig is still `motions/doll.rig.json`, so a `motions` entry's `rig` is the rig file of the doll its clips pose.
